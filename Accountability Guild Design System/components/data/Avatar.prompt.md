Italic-serif initial placeholder — no photo uploads, no AI portraits. Ground color is deterministic per user id across five tokens (ink, accent, dust, shadow, sage). `AvatarStack` overlaps avatars for member rows.

```jsx
<Avatar initial="B" userId="user_82" size="lg" />
<AvatarStack more={3}><Avatar initial="M" userId="u1" /><Avatar initial="L" userId="u2" /></AvatarStack>
```
