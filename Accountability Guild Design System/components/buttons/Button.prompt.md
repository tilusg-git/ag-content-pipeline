The primary call-to-action control — ink-filled by default, with secondary/ghost/destructive variants and an optional italic-serif arrow affordance.

```jsx
<Button variant="primary" arrow>Start a Cycle</Button>
<Button variant="secondary" size="sm">Cancel</Button>
<Button variant="ghost">Skip for now</Button>
<Button variant="destructive">Delete group</Button>
<Button loading>Saving</Button>
```

Variants: `primary` (ink fill), `secondary` (outline), `ghost` (no border), `destructive` (error outline). Sizes: `sm` (34px), default (44px), `lg` (54px), `block` (100% width). `arrow` appends the italic serif "→" used across marketing CTAs.
