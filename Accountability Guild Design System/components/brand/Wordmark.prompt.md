The Accountability Guild wordmark lockup — italic Newsreader "Accountability" + tracked Inter Tight "GUILD". `inline` is the primary logo; `stacked` and `flag` are sanctioned alternates for splash screens, footers, and column headers.

```jsx
<Wordmark />
<Wordmark variant="stacked" kicker="Vol. 01" scale={2} />
<Wordmark variant="flag" kicker="Cycle 07 · Invite" />
```

Never set the wordmark in any type other than Newsreader italic + Inter Tight; never double the tally rule.
