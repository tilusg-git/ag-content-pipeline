# Accountability Guild — Terminology Glossary

**Status:** Ratified 2026-07-20. Canonical terms and casing for product, marketing, and content. Read before writing any user-facing copy. Consistency here prevents the drift already seen in the repo (e.g. "kitty" vs "group fund").

## Canonical terms

| Term | Casing | Definition | Notes / avoid |
|---|---|---|---|
| Accountability Guild | Title | The product's full name. | Always full name on first mention and in core website/UI copy. |
| AG | Caps | Shorthand for Accountability Guild. | Internal + Field notes/blog only, after full name established. Never in core website copy, product UI, or first mention. |
| cycle | lowercase | The recurring period (weekly/bi-weekly/monthly) a group runs. | The core unit of the product. Not "round," "sprint," "period." |
| commitment | lowercase | A member's own measurable promise for the cycle. | Not "goal," "task," or "habit" in product copy. |
| forfeit | lowercase | The amount owed when a commitment is missed. | Canonical over "penalty," "fine," "fee." Verb: "forfeited." |
| kitty | lowercase | The pooled fund of collected forfeits, held for the group. | **Canonical.** Retire "group fund" / "Group fund" (5+ repo uses) — reconcile to "kitty." |
| at-stake | hyphenated | The forfeit amount a member has on the line for a cycle. | "$25 at-stake." Keep hyphen consistent (repo mixes "at stake" / "at-stake"). |
| hall pass | two words, lowercase | An allowance that excuses a miss without a forfeit. | Repo uses "Hall-pass"; **standardize to "hall pass"** (two words, no hyphen) unless starting a sentence. |
| receipts | lowercase | The proof/report at cycle close. "Close with receipts." | Brand phrase — keep. |
| proof | lowercase | Evidence logged during a cycle (notes, photos, tallies). | Not "check-in" or "update." |
| report | lowercase | The short summary each member submits at close. | |
| standard | lowercase | What the owner/group sets at cycle start (cadence, forfeit, hall passes). "Set the standard." | Brand phrase. |
| cadence | lowercase | How often the cycle repeats. | Weekly / bi-weekly / monthly. |
| Standard group | Sentence | The one free plan. | Product/plan name — capital S only. |
| owner-led | hyphenated, lowercase | Group mode where one person sets terms and reviews. | |
| peer | lowercase | Group mode where members jointly set terms; synchronous close. | "peer group," not "peer-to-peer." |
| platform fee | lowercase | The $1 AG charges per forfeit charged. | The only company revenue besides card processing. |

## Product self-reference

The product refers to itself as "Accountability Guild" or not at all. "We" is allowed sparingly in About/support/policy contexts only (see voice-and-tone.md). Never "the app" in marketing; "the app" is acceptable in support/help text.
